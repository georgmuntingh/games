            Storage

            Opening a folder reads and writes real .md files. Point it at a folder inside an Obsidian vault and the notes are yours. Each subfolder holding a _project-… file is a project; every other folder is left alone, and only files this app created are ever removed.

            A folder always opens read-only. If the vault syncs between devices, this tab cannot tell a folder that has finished syncing from one that is still catching up — so it writes nothing until you say so, and re-reads the folder when you do.

            No phone browser can open a folder, so on a phone the way to the same .md files is Dropbox itself. Create an app at dropbox.com/developers/apps with App folder access and the files.metadata.read, files.content.read and files.content.write permissions, add this page's address to its redirect URIs, then paste the app key here. The app folder is the only thing it can ever see.
